# 筑计划 · 个性化学习工作台

一个纯前端的个性化学习计划与复盘工具。无需注册、不联网也能用，所有数据保存在你自己的浏览器里，可随时整包导出备份。

## 在线使用

打开 Pages 地址即可，首次进入会有 17 步鼠标引导，跟着点一遍就能上手。

## 功能一览

- **学习计划**：多计划管理、任务分组、子任务、优先级、截止日期、日/周/月循环、模板一键套用
- **执行与打卡**：每日签到与连续天数、今日待办、逾期提醒、四象限拖拽、番茄钟、完成任务记录实际用时
- **数据看板**：完成率、学习时长、科目占比、优先级分布、打卡热力图、周/月报告、看板截图导出
- **复盘沉淀**：每日/每周复盘、疑问清单（可从复盘自动生成且去重）、知识点摘录、错题本、按科目筛选、TXT 导出
- **通用体验**：深浅色主题、全局搜索、快捷键（1-5 切换页面 / N 新建任务 / T 开始番茄钟）、数据快照与回滚
- **存储**：localStorage 本地存储、JSON 全量导入导出、一键载入示例数据、一键清空

## 本地运行

直接双击 `index.html` 即可（所有依赖已随仓库提供，不需要联网）。

想用网址访问，在仓库根目录执行：

```bash
python -m http.server 8123
```

然后打开 `http://127.0.0.1:8123/`。

## 目录结构

```
index.html          页面入口
css/main.css        全部样式
js/store.js         数据层：本地存储、模板、示例数据、导入导出
js/app.js           业务逻辑：视图、任务、打卡、图表、番茄钟、教学引导
vendor/             Chart.js / html2canvas / SortableJS（离线副本）
```

## 说明

- 数据只存在本机浏览器 localStorage，不上传任何服务器；换设备请用「导出数据」→「导入数据」。
- 首次引导可随时在「设置」里点「重新观看功能教学」重看。
